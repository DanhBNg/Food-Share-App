🚀 Cách chạy project
1. Clone project:
- git clone <repo-url>
- cd food_share

2. Cài package: flutter pub get

3. Cấu hình Firebase & Supabase:
- Thêm file google-services.json vào: android/app/
- Cấu hình Supabase trong image_upload_service.dart

4. Chạy ứng dụng: 
flutter run

Build APK: 
flutter build apk --release

🎯 Mục tiêu của dự án

Giảm lãng phí thực phẩm

Tạo cộng đồng chia sẻ thân thiện

Kết nối người có nhu cầu với nguồn cung gần nhất

Hỗ trợ hoạt động thiện nguyện và môi trường
